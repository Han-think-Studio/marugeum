# 삽화 넣는 곳

파일 이름만 맞추면 코드 수정 없이 바로 쓰인다. 없는 파일은 조용히 무시된다.

- `scene-<종류>.png` 정사각형(1024×1024). 종류: start, peak, pass, temple, shelter, village, valley, spring, military, goal
- `event-<이벤트 id>.png` 가로 띠(3:1, 1536×512). id 는 `src/data/events.ts` 의 id
- `title.png` 제목 화면 배경(16:9, 1920×1080)

전체 목록과 프롬프트는 `docs/art-list.md`.
